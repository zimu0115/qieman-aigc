# D07｜美术设定与资产生成

从文字分镜提需求，把人物、场景和道具做成可用资产。

> 同一短剧的人物、场景、道具采用资产包，附一张人景物组合试图、修改对照及镜号引用表；缺项明确交给D8补齐。

## 本日交付与课型

上午：一页美术设定与资产需求单：含风格采用理由、两位角色的基础形象，以及主角色一项必要角度或状态的本人制作记录。

下午：同一短剧的人物、场景、道具采用资产包，附一张人景物组合试图、修改对照及镜号引用表；缺项明确交给D8补齐。

课型：两半天均以B类实训为主，本人制作、写作、试读与交接是验收主体。

主干：美术设定→人物资产→场景道具→组合交接

### 本日位置：先建立设定，再安排具体画面

D6已经说明每镜要发生什么，今天据此准备反复使用的外观和空间依据。人物资产回答是谁、穿什么；场景资产回答这是哪里、有哪些固定关系；道具资产回答是什么、怎样被使用。D8才把这些依据组合成每一镜的构图、机位与动作。今天的俯视关系图用于说明店内布局，组合试图用于暴露资产冲突，均不代替整条画面分镜。

### 1．从文字分镜提取需求，不按镜数凑资产

先读当前采用稿，逐镜圈人物、地点、重要物件，再读动作带来的角度和状态：回头需要侧面，背影需要背部服装，拿杯需要手持关系，指菜单需要清楚文字与可指的位置。资产清单、设定图、分镜图分开理解：一张角色参考可服务多镜，一镜也可能用多类参考。每项写使用镜号、已有／需补、确定／待设计／待确认。只在对白中被提到、画面不出现的人物，不自动增加人物生图作业。

### 2．美术设定先做选择，再写提示词

用同一故事比较两种视觉候选，说明哪一种符合时代、职业处境和叙事气氛。本课练习选择两种只是为了看清差别，不是固定生产数量。参考旁写「借什么、用在哪、哪些不带入」。把提示分为可复用风格、本图内容、必须保持的条件。例如朴素日常喜剧可采用自然肤色、普通店员围裙、明确柜台与菜单；暗黑霓虹、满脸高光不是加入「电影感」就必须出现的元素。人物、场景、道具共享表现形式、材质、主辅色与光源依据。主色落到墙面或衣服，点缀落到重要物件；不把颜色含义和60／30／10当硬规则。单场景先写一组光色关系，只有剧情改变才补状态；完整多场色彩脚本作拓展。

### 3．人物设计：先选基础形象，再扩出需要的资产

先写身份与处境，再写可见外形：年龄阶段、脸部结构、体型、发型、服装轮廓和必要识别点。记忆点可以帮助辨认，不能用装饰代替稳定的脸与服装。先选基础候选，再扩角度和状态，避免一开始就做多张互不相像的脸。文生图用于寻找候选；图生图和多图参考用于约束已有方向，分别说明哪张提供面貌、发型、服装或姿态。保存完整提示词与采用参考，后续才知道怎样改。人物文案提供这两条路径及skill的组织方式；课堂把它用于本人项目，不承诺某个平台名或某句提示词必然提升质量。

### 4．人物资产的覆盖范围，由镜头决定

认识面部多角度与全身正、侧、背的用途：近景看五官，正面全身看体型着装，侧面看轮廓和厚度，背面看后脑与服装结构。45度不等于90度侧面。今天讲清各自用途，再按本片实际镜头制作，不能因为短片就一律省侧面，也不强制所有角色做九宫格。至少给主角色补一项实际所需角度或表情／服装状态；另一角色明确采用与缺项。先确认脸、发型、衣服细节是否仍属于同一人，再收入资产。表情图展示一个状态，动态表演的变化留D9。

### 6．场景设计：让同一空间能容纳行动

先准备空场景基准，写明年代、地点、昼夜、门窗、柜台、菜单与人物活动区。用简单俯视图标两人、入口和重要物件，再补实际需要的观看方向。一张店铺正面图没有自动提供另一面墙；反向环境不能只把同一背景镜像。两个方向应共享门窗、柜台和菜单的相对位置。场景设计保留能定位的参照物，减少无关杂物，留出指菜单和接递物件的空间。三维、全景与九宫格都是可选工具，本日用现有图加简易关系图完成基础任务。

### 7．道具设计：外形、用途与状态一起固定

优先单独建立承担线索、被拿取或跨镜反复出现的物件。菜单写什么、杯子长什么样、由谁拿、怎样拿，比随机生成更多背景装饰重要。记录轮廓、颜色、材质、相对大小、关键细节与使用状态；需要操作时补持握或开合依据，只有白底外观图不一定够用。菜单关键字需按采用脚本制作，可用可编辑文字排版，不能让不可读字承担反转。没有拿起杯子的情节就不新增持杯动作。虚构道具可设计未见部分并标采用，真实产品未知结构先列缺口。

| 对象 | 设计与制作任务 | 如何知道够不够用 |
| --- | --- | --- |
| 顾客 | 赶时间的普通顾客，外形与衣着支持处境；采用清晰身份图和本场着装，按镜头补侧脸或反应状态 | 转向后仍像同一人；没有靠加一句台词代替画面设计 |
| 服务员 | 与顾客身份可区分，工作服和发型固定；可复用已采用角色，按本次环境调整必要状态 | 正反方向服装结构对应；不能每镜随机换围裙 |
| 店内空间 | 固定柜台、菜单、入口和站位，先空场景，再补需要的反向环境或明确缺项 | 俯视图与两个观察方向对应；人物有指向与交流空间 |
| 菜单 | 使用采用稿的关键文字，保留清楚字样、位置和可编辑稿 | 在后续预期画幅能辨认；手指不能遮掉揭示信息 |
| 杯子 | 仅在采用稿出现或被操作时单独固定杯型、颜色与当前状态 | 同一物件跨镜可辨认，数量和所在位置有依据 |

### 上午闭卷题

资产清单、设定图与分镜图分别说明什么？给主角色补一张图时，怎样决定角度、状态和参考用途？

参考要点：清单说明需要什么和用在哪里，设定图固定外观与空间，分镜图安排具体镜头。根据采用文字分镜的可见角度、动作和状态补图；说明身份、服装或姿态由哪张参考提供，再与采用角色对照，不按宫格数量凑图。

### 下午闭卷题

一套人物、场景、道具资产怎样交给画面分镜？组合图出现不一致时，怎样定位并选择修改方式？

参考要点：给采用单图、风格与空间说明、对象状态、版本、真实入口和镜号用途，列未补项。先查实际引用及各图职责，再看身份服装、空间比例、光色、道具文字和使用关系；局部错误保留满意部分定点改，整体关系冲突回可靠参考重新组合，修改结果仍需比较。

每题在下一半天开场同题回测，周五题在下周一回测；D20结课题在下一次辅导回测。

| 个人验收项 | 标准 |
|---|---|
| 需求与设计 | 资产来自采用文字分镜；风格、服装、光源或道具设计能说明故事用途 |
| 人物 | 两角色有采用依据；本人至少完成一个角色的设计和必要衍生，身份与着装可对应 |
| 场景与道具 | 空间关系支持行动；关键物件的外形、文字和状态可用，未见方向明确处理 |
| 组合与交接 | 有实际组合试图、问题与修改记录，单图入口和镜号用途能被同伴找到 |

没有完成时：工具排队时继续做需求拆解、空间草图、菜单可编辑稿和采用记录。统一故障超过8分钟用已标注的教师图练判断与组合；本人生成未完成就记缺项，恢复后优先补，不把教师素材记成本人成果。范围超量先保住两角色、一个场景和关键道具，复杂差分留缺项。

### 班级怎样运转

30—40人按3—4人组成互查组，每人保留自己的项目与采用判断。组内轮换制作、审核、接收角色，互查不替代主讲验收。1名助教先处理文件与工具问题；有第2名助教时，再分管另一半教室。主讲在两个练习检查点收集共性问题，集中演示一次。
