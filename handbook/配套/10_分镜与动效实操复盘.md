### 能教给学生的判断顺序

1. 这张图要让观众明白哪一句话？
2. 用目录、比较、步骤还是截图更合适？
3. 参考图分别负责内容、布局还是风格？
4. 首版最影响理解的是哪一处？
5. 修改哪个对象、怎么变、哪些已认可条件保持不变？
6. 为什么采用这一版，下一步还缺什么？

这是从实际迭代提炼的顺序，不是将所有历史反馈机械做成必须重复的步骤。

## 三、字体与风格：保留个人选择，讲清通用方法

牧老板曾逐步选择标题、小标题、正文、英文的不同字体角色，并反复调整字号与间距。重要的是先建立角色与层级，再让每次生成沿用。生成图中近似字形仍须按实际结果判断，不能仅因为提示词写了字体名就认定完全一致。

后期规则包括1440×1080、为下方字幕保留空间、使用指定背景原文件、独立标签与相连图卡底部标签区别处理。主标题英文使用Quentin、橙色等是本项目后期选择。早期图片采用不同尺寸、英文位置或圆角方式，保留为历史试验，不把它们改造成假的最新定稿。

在课堂中，学生需要能解释信息层级和选型理由；不要求所有人复制黑石、纸张或油画风格。页面本身继续采用现有简洁排版，案例图保留其自己的视觉风格。

原图中的libTV提示词对比只用于分析画面设计，不作为某句提示词有效性的实验结论。原口播中的工具能力、模型说法也不能因进入案例就自动成为可靠知识；课堂只采用有明确依据的概念。

## 五、动效实践：从能动到合适

### 圈线与箭头的四版

来源：「Remotion子牧动效Skill」T001—T006及现存圈线v4工程。

- v1先做1秒效果，包含后来被明确去掉的左箭头。
- v2改成3秒，但速度变化仍不够明确。
- v3明确慢快慢，继续调整动作关系。
- v4改为2秒，箭头与圈线错开3帧开始，运动互相重叠；去掉左箭头。

现存v4参数为60fps、1448×1086。右箭头0秒开始，圈线0.05秒开始，各运动1.2秒；完成后留住画面到2秒。学生应先说秒，再按当前帧率理解帧，不把历史3帧直接套到所有项目。

### 资产文字运动的三版

来源：资产运动测试任务`01a09f30-be40-7c31-827b-4805ad2312cf`的T001—T006，以及三个现存源工程。

- v01为2秒首版，输入背景尚不完整。
- v02将位移和缩放作为同一个动作；总长改为5秒，但文字动作仍约1.5秒完成。用户随后明确肯定已有动效。
- v03只处理随后提出的播放问题：背景视频从淡入开始就播放，不等待淡入结束；已认可的文字运动保持。

v03为30fps、1600×1200、5秒。文字先停0.5秒再运动1.5秒；视频在1秒开始播放并淡入0.5秒，约4秒播放结束并保持末帧到5秒。已有文件不等于用户后来再次确认，本次保留这一边界。

### 转成四个好理解的时间概念

| 概念 | 学生怎样描述 |
|---|---|
| 总时长 | 这段从开始到结束一共几秒 |
| 动作时长 | 这一张卡从出现到稳定用了多久 |
| 开始间隔 | 第二张比第一张晚多久开始 |
| 停留 | 动作完成后留多久让人看清 |

再加一个媒体判断：播放开始和透明度变化可以同时进行。先定位问题，再提出局部修改；不让初学者背代码实现。

### 静态：把感受转成可以执行的修改

| 过程 | 牧老板的实际判断 | 提炼到课堂 |
|---|---|---|
| 灰色原型从细到简 | 删除过细的文字图表；保留头肩轮廓、内容区与字幕区 | 原型管位置与信息角色，不提前锁定具体内容 |
| 清晰人物→模糊人物 | 先让文献成为视觉重点 | 模糊服务注意力分配，不是所有画面的固定装饰 |
| 暗角与重噪点版 | 太黑、噪点太多，不要把人物也变成黑白 | 背景颜色与主体颜色分开；纹理不能抢阅读 |
| 提亮后的硬描边版 | 去掉硬边，强调材质和自然层次 | 用明暗、材质、柔和阴影分离，不能只会加粗描边 |
| 静态第五版 | T007明确认可 | 采用条件写清，保留之前被否定的版本用于解释判断 |
| 预模糊人物不好去底 | 另行要求清晰人物，去底后再加模糊 | 清晰原件先存，模糊留到合成时控制 |
| 棋盘格被画入PNG | 要真正透明的人物与素材 | 文件后缀不等于透明，换底板观察边缘和固定格子 |

### 动效：七版怎样逐步收敛

| 版本 | 主要变化 | 后续仍在解决什么 |
|---|---|---|
| v1，5秒 | 做出第一条入场视频 | 入场太长、人物棋盘底 |
| v2，2秒 | 压缩入场与总长 | 又过快，需要更合适的速度变化 |
| v3，3秒 | 拉长动作区间，增加缓动 | 人物边缘不好，方向和标签仍需修改 |
| v4，统一向上 | 清晰人物后模糊；直接用已有姓名牌 | 原位置大小与六个独立起点 |
| v5，六元素错开 | 文档、人物、姓名牌分别开始 | 去掉淡入，从画外开始，继续对齐库克 |
| v6，纯位移 | 保留统一方向与错开 | 库克再左移80像素，模糊28→19 |
| v7，采用版 | 只改最后的对齐与模糊 | T010明确满意，停止追加效果 |
