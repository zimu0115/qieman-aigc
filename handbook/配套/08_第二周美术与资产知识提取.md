# 第二周美术与资产知识提取

本轮按牧老板最新确定的顺序编排：文字分镜→美术设定与三类资产→画面分镜与有声预演→视频生成→剪辑交付。

2026年9月16日重新取得指定文件夹中的8篇知识稿，以及「人物资产」文案、画板节点和26张原始图片；随后以牧老板补充的本地素材文件夹为主整理，合并重复项后共66张图片、1段视频，已全部收录。重点研读需求、风格、光色、角色、场景道具、组合试制和交接的相关章节；LoRA仅保留拓展入口。下文区分资料中的方法、案例条件和本班教学安排。

## 一、周二与周三怎样分工

| 环节 | 要回答的问题 | 留下的东西 |
| --- | --- | --- |
| 周一文字分镜 | 每镜发生什么，观众得到什么信息 | 文字表、关键草图、声音与估时 |
| 周二美术设定与资产 | 人、景、物怎样设计，哪些外观和关系要固定 | 设定卡、三类采用资产、组合试图、镜号用途 |
| 周三画面分镜 | 从哪里看，怎样摆，前后怎样连，实际要多久 | 整条画面分镜、有声预演、逐镜生成输入 |

周二的空间关系图说明店内布局，组合试图暴露资产冲突；周三才安排完整镜头。周三新增角度或起始画面沿用周二设定，按实际镜头补齐。

## 二、重新提取的核心知识

| 知识 | 教师要讲到的具体内容 | 学生实际做什么 | 来源定位 |
| --- | --- | --- | --- |
| 需求拆解 | 从采用剧本和文字分镜提人物、场景、道具，再找角度、动作、状态；清单、设定图、分镜图职责不同 | 在原镜头表补已有、需补和对应镜号 | 03-01「先把本次美术任务说清楚」「用分镜补齐角度、空间与连续状态」 |
| 美术方向 | 时代、人物处境、视觉形式、材质、光色要能相互支持；参考说明借什么、不带入什么 | 用同一故事比较两个候选，记录采用理由 | 03-02「情绪板要能解释选择」「把风格、具体内容和锁定条件分开」 |
| 光色关系 | 主辅色落到对象，光线有空间来源；变化要有剧情依据 | 为单场景写一组颜色与光源说明，让三类资产共享 | 03-03「主色、辅助色与点缀色要落到对象上」「先确定光从哪里来」 |
| 人物基础设计 | 人物身份、经历与当前处境转成可见形象；先选基础候选，再扩角度和状态 | 主角色本人设计生成，另一角色明确采用来源 | 03-04「先写清身份、外形与当前状态」「先选择基础形象」；人物资产「对应文案」 |
| 多图参考分工 | 面部、体型、发型、服装、姿态和风格参考可以不同，必须写职责并实际接入 | 保留完整提示词、实际参考和采用结果 | 人物资产文案的文生图、图生图路径；03-07「明确每张图提供什么」 |
| 人物角度与差分 | 面部近景看身份，全身正侧背看结构；表情、换装和剧情状态与同一人对应 | 按镜头补一项必要角度或状态，标仍需补什么 | 03-04「三视图」「表情服装差分」「全身小脸与高清面部冲突」 |
| 场景空间 | 空场景、出入口、活动区、固定参照物和不同方向应互相对应 | 建一个空间基准与关系图，补镜头需要的方向 | 03-05「把空间设计成可以发生行动的地方」「同一空间的不同方向」 |
| 关键道具 | 轮廓、材质、颜色、尺寸、细节、使用机制和状态；装饰不全部独立生成 | 做菜单等关键道具，保留准确文字或操作依据 | 03-05「给重要道具建立清晰的外形依据」「补上使用关系、功能机制与剧情状态」 |
| 组合与修正 | 查实际引用，分开定位身份、空间比例、光色与手持关系 | 做一张代表性组合试图，保留一次修改对照 | 03-07「资产名、连接线与真实引用」「选择有代表性的画面」 |
| 采用与交接 | 总览便于理解，清晰单图便于调用；文件名不等于采用状态 | 同伴实际找到某镜所需资产，记录采用版、缺项和入口 | 03-08「总览图方便理解」「让每个制作任务找到对应素材」 |

人物信息卡汇总面部、正背参考、服装配件与颜色；完整单图在周二教案中分别展示。

| 资料里的说法 | 教案采用方式 |
| --- | --- |
| 用人物小传帮助形成气质 | 让学生把身份、处境转为发型、服装、体态等可见条件，仍需人工选择 |
| 多张图分别提五官、发型、服装 | 保留参考分工与采用记录；结果是否符合目标看实际图 |
| 先定母图，再扩配套 | 作为周二人物制作的主顺序 |
| 面部与全身多视图 | 教清正、侧、背与面部角度用途，实际制作按本片需要安排 |
| 侧面全身可以省掉 | 改为按镜头和结构需求判断；侧面承担重要信息时仍需补 |
| 全身小头需要去掉 | 限于大小脸冲突或实际结果误用身份时处理，不一律去头 |
| 原图不能反复编辑 | 与03-07结合：局部错且整体满意可局部改；整体关系错或画质累积劣化时回可靠输入 |
| 某句提示词必然提质、融合后一定安全 | 不作为课堂通用结论或保证；保留可观察的过程与采用理由 |

## 五、本班如何控制一天的范围

周二继续单场景、双角色、单一反转短剧，复用合适的已有资产。上午完成需求与风格卡、角色基础形象；下午完成场景、关键道具、组合修正与交接。

| 层级 | 课堂安排 |
| --- | --- |
| 必教 | 三类资产需求、美术选择、角色身份与着装、基础视图用途、空间方向、道具状态、引用分工、采用交接 |
| 必做 | 两位角色采用依据，其中至少一位本人生成与必要衍生；一个场景基准与空间图；至少一件关键道具；一张组合试图与修改记录 |
| 按镜头补 | 侧背面、反向环境、特定表情、服装或道具变化、手持关系 |
| 拓展 | 完整多场色彩脚本、复杂三维／全景、LoRA训练、大规模换装与连载资产体系 |

周三用简笔画、资产拼摆或AI辅助出图完成整条分镜，重点是可读、连续、有时间依据。没完成的必要输入明确记录，D9先处理相关小样；不能以降级为由把关键故事信息删掉。
