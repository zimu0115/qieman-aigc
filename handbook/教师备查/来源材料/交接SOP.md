# 在原任务入口，完成一次提交与接收

## 这份配套怎样使用

本配套承接[《环节交接、审核修改与最终交付》](https://sakuraoxo.feishu.cn/docx/CgtFdO2vzoMaYoxkV9UcdsBvnWg)。只提供两类核心记录：提交与接收、问题与修改。分批交接、临时接班和最终交付都沿用这两类信息，不另建同用途总表。

优先在[现有任务或镜头记录](https://sakuraoxo.feishu.cn/docx/K16RdbfwloKBawxlnNlczhyhnDh)补缺项；没有相应位置时再复制下面空白模板。时间与实际投入引用[任务排期与工时记录](https://sakuraoxo.feishu.cn/docx/STywd6d8JoT4P7xkMlMc901MnUb)，文件与采用位置沿用[资产文件规范](https://sakuraoxo.feishu.cn/docx/UqTadZYAeoDxDpxSL3bcvhoYngh)。教学课程链接是填写方法入口，不是学生项目的真实结果位置。

**提交人填本次事实，接收人填自己的实际回应。没有打开、确认或真实新结果，就保留相应待办。**

空白项用方括号提示要填什么；填写时替换为自己的真实信息。已在原任务里明确的字段用同一入口引用，不重复抄写。以下医院示例全部为课堂模拟，文件名和过程事件用来示范，不代表已经创建视频、发送文件或得到真实审核。



## 简明SOP

1. 提交前读本轮要求，打开准备交出的实际对象，确认范围、版本、限制和下一步。
2. 提交人填写表一前六项，把说明放回原任务，并按项目允许的渠道提醒指定接收人。
3. 接收人实际打开指定对象，对照自己接手所需的内容，再填第七项。遇到问题填表二。
4. 问题先定位，由有权的人确定修改范围；执行人改出本轮实际成果，再写重新提交。
5. 接收人与确认人按分工查看新结果，记录真实结论；明确采用后更新实际使用位置，再继续受影响的工作。
6. 到最终交付时，表一注明用途与实际交付清单；结束后留下接收结论、剩余事项和必要复用经验。

| 信息组 | 填写区 |
|-|-|

| 接收用途与责任 | 提交人：[填写]。接收人：[填写]。下一步用途：[填写]。有权确认本轮结果的人及范围：[填写]。 |
| 实际结果与版本 | 实际文件、节点或记录入口：[填写可定位位置]。版本：[填写]。性质：[采用／候选／待确认／其他实际状态]。依据：[已有采用说明或待谁确认]。 |
| 要求与当前结论 | 本轮要求入口及关键条件：[填写]。已有真实确认：[谁、何时、哪份、哪一范围；没有就写待确认]。 |
| 限制与未完事项 | 已可用部分：[填写]。未完成或缺失：[填写]。对接手的限制：[现在可做什么、不能做什么]。 |

| 接收人实际回应 | 实际打开时间与对象：[接收人填写]。可以继续的范围：[填写]。发现的问题及位置：[填写或写本次未发现阻止接手的问题]。下一步：[填写]。本回应是否包含审核确认及范围：[按实际职责填写]。 |

# 在同一条问题记录中，写完修改与重新接手

## 先定位事实，再确定改法

问题描述包含版本、位置、原要求、实际差别和影响。时间点配合镜号或动作一起写，避免改版后位置变化。原因未明就写待查，不把工具猜测或个人判断伪装成已经证实的原因。

同一原要求下的局部修正，按任务分工处理；要求改变或影响扩大，先由有权的人明确新范围。意见冲突时先问分别指哪处，不自行听最后一条。以下表格是同一问题的四个阶段，可以放在原任务的一条子记录中。



## 表二｜问题、修改与结论空白模板

| 发生阶段 | 填写区 |
|-|-|
| 发现问题 | 原任务与问题编号：[填写]。实际查看版本、入口与时间：[填写]。定位：[镜号、动作及必要时间点]。原要求：[填写或引用]。实际差别与影响：[填写]。原因：[已知事实或待查]。反馈人：[填写]。 |
| 确定本轮修改 | 确认人及实际决定时间：[填写]。本轮改动：[填写]。必须保留：[填写]。处理位置：[输入／生成／剪辑／其他]。受影响范围：[填写]。执行人、查看人和安排：[引用原任务；变化另注明]。冲突或未知：[填写]。 |
| 处理与重新提交 | 已尝试动作与实际结果：[填写]。当前进展：[提示已改／新候选已出／其他事实]。新结果入口与版本：[实际有才填]。原问题如何处理：[填写]。保留与剩余事项：[填写]。提交人及时间：[填写]。 |
| 查看结论与恢复 | 谁在何时打开哪份：[填写]。原问题结论：[解决／仍有问题／本轮不采用／另案处理及依据]。受影响前后关系：[填写]。真实采用与确认范围：[填写]。已更新的实际使用位置：[填写]。可以恢复的工作与接收回应：[填写]。未完事项及负责人：[填写]。 |

**提示词修改、产生新候选、查看通过、接入实际工程，要按已经发生的步骤写。表格后半段暂时为空，比提前写通过准确。**



## 记录中断时，仍能让别人接班

处理中需要暂停或换人，在第三项继续写当前采用、待确认对象、已试过但无效的方法、缺什么、下一步及等待谁决定。原本只确认一条节点，就写一条，不扩大为全部节点正确。

修改已影响相邻镜头时，把需要查看的衔接写出来；无关范围可继续。采用位置的替换回[模块二](https://sakuraoxo.feishu.cn/docx/RIwzdGmkuoTrnnxreQCch45an8B)，时间变化回[模块一](https://sakuraoxo.feishu.cn/docx/SM4JdzjJXoPi8BxUQnEcfcIWnrf)。一个问题未处理，不通过删记录让它消失。

# 完整填写示例：从A段接手到B段修改闭环

## 本例给定条件

> **课堂模拟｜医院短片**
> 
> 约60秒竖屏短片分为A等待消息、B医生走出并转身交谈、C听解释、D松一口气四个制作片段，约15秒一段，每段可以包含多个镜头。甲负责分镜与参考，乙负责生成与筛选，丙负责剪辑、声音和字幕，讲师确认关键结果。周三15:00提交完整初版供整体查看。
> 
> 以下模拟周二的事件顺序；日期、文件名、岗位与确认都只属于题目。A画面获准接入初剪，声音字幕由丙后做；B第一次结果缺转身。没有真实文件时，仅按给定事实练填写，不写自己已打开。
> 
> 模拟入口用“课堂工程／片段记录／A或B／指定版本”表示题目对象；真实练习应替换为教师实际提供的文件或节点位置。这些文字不是已经创建的远程链接。



## 表一填写示例：先交可以使用的A段

> **课堂模拟｜A段提交与接收**

| 信息组 | 模拟填写内容 |
|-|-|
| 范围与任务 | A片段画面，原任务为医院短片A；不含B、C、D，也不含本片最终声音字幕。 |
| 用途与责任 | 乙提交，丙接收用于初剪；讲师确认A段画面。丙负责接入及后续声音字幕。 |
| 实际结果与版本 | 课堂工程／片段记录／A／A_v02；题目给定这是讲师当前采用的画面候选。其余A候选保留为历史参考。 |
| 要求与结论 | 对照A采用分镜，女主在医院走廊等待消息；模拟周二10:00，讲师确认A_v02画面可用于初剪。该结论不包含整片、声音和字幕。 |
| 限制与未完 | A画面可用；声音字幕未完成，由丙处理。B仍待修改，不按已经通过的结果接入正式初剪。 |
| 下一步与提交 | 乙于模拟周二10:10交A；丙先接A，再按原任务等B修改。整体节点仍为周三15:00交完整初版。请求丙说明是否能找到并使用A_v02。 |
| 接收人回应 | 题目继续给定：丙于模拟周二10:20打开A_v02，确认是本次指定内容，可以接入初剪，声音字幕由自己继续处理。B待确认不会被当成通过。此回应只说明接手A，未作整片审核。 |

同一时刻，阶段入口可记“制作中：A画面已确认并接手，B待修改”。不因第一批交出，就把四段或最终片写成完成。



## 表二填写示例：B段从漏动作到重新采用

> **课堂模拟｜问题B-01的完整过程**

| 阶段 | 模拟填写内容 |
|-|-|
| 发现问题 | 模拟周二10:30，丙打开课堂工程／片段记录／B／B_v01。定位为医生走出门后本应转向女主的位置。分镜要求医生走出并转身交谈，实际没有转身，接C的对话对象关系不清。原因为待查，不能只凭结果认定提示词或工具哪项出错。 |
| 确定修改 | 模拟周二10:45，讲师决定本轮补医生转身。保留人物造型与走廊方向；乙处理B，丙查看是否可接C，讲师确认本轮画面。不改变A；若B结尾位置变化，应同时查看B至C。此次仍按原安排推进，尚无新增交期决定。 |
| 中途真实进展 | 模拟周二11:00，乙只完成提示词调整，尚无新视频。记录为“提示已改，新候选待制作；不能据此标B_v02视频完成”。丙继续不受影响的A，B保持待处理。 |
| 新结果与再提交 | 题目继续给定：模拟周二13:00，乙实际制作并提交课堂工程／片段记录／B／B_v02。说明本轮补转身，造型与走廊方向保留，声音字幕仍由丙处理；请查看动作与B至C关系。B_v02当前待确认，B_v01不再作为新提交结果。 |
| 查看与决定 | 题目给定：模拟周二13:15，丙打开B_v02并与C当前采用片段连看，确认转身可见且可以接C；模拟周二13:30，讲师确认本轮B画面采用。丙的接手判断和讲师的采用决定分别保留。 |
| 实际更新与恢复 | 题目给定：模拟周二13:40，B原记录采用改为B_v02，丙把剪辑实际使用对象替换为B_v02，再留回应“已接入本轮采用B；A未改，C衔接可继续”。B-01记本轮已解决。声音字幕和整片查看仍待后续，不包含在本次画面确认中。 |

若13:00实际只交了新提示词，后面的候选查看、采用和接入事件就都不能填写。表中后半段成立，是因为本题明确给出了这些后续事实。

这条记录同时保留原要求、实际差别、修改范围、中途状态、新结果和重新接手，不需要另做一份修改总表。原问题已解决的依据，是实际结果和本轮结论，不是版本数字变大。

# 最终交付与临时接班，继续使用同一记录

## 最终交付只补本轮用途与清单

沿用表一的责任、要求、状态和接收回应，在实际结果一项增加下表清单即可。真实项目已有交付清单就直接引用，不复制第二份。

| 交付对象与用途 | 实际入口及版本 | 本轮包含与限制 | 真实确认与接收 |
|-|-|-|-|
| [成片／工程／资产等；按实际约定填] | [可定位实际文件或工程，版本] | [画面声音字幕／工程依赖／缺项及影响] | [谁何时确认哪份；接收人实际打开与结论] |
| [需要另一份才填写] | [填写] | [填写] | [填写] |

交成片不等于交可编辑工程。需要工程时，补实际软件环境、工程对象、依赖素材和接手限制；按该软件已有方法交接，不凭本表猜测打包按钮。最终要求只包含成片，就不自行扩大为全部工程资产。



## 最终交付完整填写示例

> **课堂模拟｜完整初版之后的交付事件**
> 
> 承接前例，题目额外给定：周三15:00交出完整初版供查看，之后按讲师反馈完成一次修改。本轮最终约定交一份约60秒竖屏可播放成片，包含中文声音和中文字幕；不包含可编辑工程或后续发布。以下周四事件是新增的课堂假设，不是模块一原先已经确定的交期。

| 表一信息组 | 模拟填写内容 |
|-|-|
| 范围与任务 | 医院短片本轮采用成片，A至D完整内容；不含工程移交和对外发布。 |
| 对象与用途 | 丙提交，讲师接收用于本次课堂成果留存；讲师确认内容采用。 |
| 交付清单 | 一份：课堂工程／导出／医院短片_课堂采用_v03.mp4。题目给定实际文件可定位，约60秒竖屏，中文声音与中文字幕齐备。工程与原素材沿原项目入口保留，本轮不列为交付物。 |
| 要求与确认 | 对照题目补充的最终交付要求。模拟周四10:00，讲师对v03完整内容作本轮采用确认；周三的初版提交记录保留，不改成当时已最终通过。 |
| 限制与未完 | 本轮约定成片无剩余待处理项。后续发布未列入任务，不能写已发布；工程接续要求也未在本轮发生。 |
| 提交动作与时间 | 题目给定：模拟周四10:30，丙打开准备交出的实际导出文件，从头到尾查看，确认是本轮v03而非旧导出。11:00按约定提交实际文件和入口，等待接收回应。 |
| 实际接收 | 题目给定：模拟周四11:20，讲师打开该实际文件，确认本轮约定成片收到且内容对应v03。记录本次实际接收，项目入口关联该文件与采用结论。本轮交付结束。 |

若只有11:00提交而没有11:20回应，就仍记待接收；如果工程后来成为新增要求，另明确范围与输入后再交，不能假装本次已经一并移交。

# 留下结论与复用条件，不重复维护记录

## 结项与SOP补充栏

项目原入口能找到本次结果与结论即可。以下内容按需补在原任务尾部；不需要重新制作排期、工时或资产总表。

| 结项信息 | 填写区 |
|-|-|
| 本轮结束范围 | [实际交付与采用入口，真实接收结论；还有待办时写清去向] |
| 值得保留的变化 | [原问题、改变理由、已尝试方法、实际结果和使用条件] |
| 下次复用动作 | [何时使用、需要的输入、责任人动作、交出成果和确认职责] |
| 限制与停止条件 | [缺什么不继续、哪些结论仅局部成立、何时回到有权者决定] |
| 原记录位置 | [任务工时入口、资产版本入口、现有SOP位置；不另抄相同数据] |

> **课堂模拟｜从B段问题留下一个可复用动作**
> 
> 本轮结果：B补转身后得到采用，实际剪辑已换B_v02，声音字幕与整片结论另见最终交付记录。原问题是缺少指定动作，不是所有镜头都需重做。
> 
> 可复用动作：同类片段重新提交时，列出原动作要求、新结果位置、实际补到哪里及需查看的相邻片段。只修改提示时，状态写提示已改、新结果待制作。接手人在实际打开后说明可继续范围，确认人另留采用决定。
> 
> 限制：该动作适用于已经明确原要求的局部修改；如果人物造型或故事方向也改变，先明确新范围。不能把本次B至C可接，写成所有后续镜头都无需查看。相关信息留在B原任务，不再增加一张“B交接总表”。
